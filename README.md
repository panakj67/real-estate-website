# real-estate-website

# 🏡 Real Estate Website (MERN Stack)

A full-stack real estate listing platform that allows users to explore, add, and manage properties with ease. This project is built using the MERN stack — MongoDB, Express.js, React.js, and Node.js — and features a clean, responsive user interface.

---

## 🔧 Tech Stack

- **Frontend**: React.js, CSS/Tailwind CSS
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Authentication**: JWT
- **Deployment**: Coming soon

---

## 🚀 Features

- 🔐 User Registration and Login
- 🏘️ Add, View, Edit, and Delete Property Listings
- 🔍 Property Search and Filter
- 🖼️ Upload Property Images 
- 📱 Fully Responsive Design
- ✉️ Contact/Enquiry 

---

## ⚙️ Getting Started Locally

```bash
# 1. Clone the repository
git clone https://github.com/panakj67/real-estate-website.git

# 2. Navigate into the project directory
cd real-estate-website

# 3. Install frontend dependencies
cd client
npm install

# 4. Install backend dependencies
cd ../server
npm install

# 5. Start the frontend
npm start

# 6. Start the backend (in a separate terminal)
npm run server
